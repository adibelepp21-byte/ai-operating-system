FOUNDER SELECTION

R1 — CONSUMPTION BY REAL SYSTEM WORK

R1 is hereby established as the authoritative acceptance interpretation for
E12-06.

capability/state is consumed by real AIOS system work.

The acceptance chain is therefore:

REAL SYSTEM WORK → REAL CONSUMPTION → OBSERVATION → INDEPENDENT VERIFICATION →
EVIDENCE → E12-06 DETERMINATION

fixture, or merely callable surface is not by itself sufficient evidence of
consumption by real system work.
