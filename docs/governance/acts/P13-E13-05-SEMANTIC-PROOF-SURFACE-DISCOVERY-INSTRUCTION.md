4. ACCEPTED MINIMUM MEANINGFUL STATE CHANGE

The following five requirements are already accepted:

B1 — State Before Known

P13 must actually know the relevant state before acting.

B2 — P13 Determines the Action

The test runner must not prescribe the action and merely ask P13 to execute it.

B3 — Real State Change

The action must produce an actual state change.

No simulated mutation.

No mock-only success.

B4 — Expected Consequence

P13 must have a reason to expect a particular consequence from the action.

B5 — Resulting State Observable Again

The resulting state must be observable by P13 after execution and must feed the subsequent re-observation / rediscovery loop.

Meaningfulness is defined by causal relationship:

   ↓

   ↓
