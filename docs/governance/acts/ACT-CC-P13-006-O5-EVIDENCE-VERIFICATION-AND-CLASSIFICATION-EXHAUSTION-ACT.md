NOT FOUND ≠ FALSE

12. SOURCE AUTHORITY TEST

For every claimed canonical source, Claude Code shall determine:

SOURCE EXISTS
        ↓
SOURCE IS RESIDENT
        ↓
SOURCE IS AUTHORITATIVE
        ↓
SOURCE ACTUALLY SUPPORTS THE ITEM

All four conditions are necessary before an item is classified as:

DIRECTLY VERIFIED

A source merely existing is insufficient.

A document merely calling itself canonical is insufficient if repository
authority establishes otherwise.

A preparation record pointing to a source is not equivalent to direct
inspection of the source.

13. PREPARATION-RECORD BOUNDARY

The following distinction shall be preserved:

PREPARATION-RECORD EVIDENCE
        ≠
DIRECT SOURCE EVIDENCE

A preparation record may legitimately establish that a prior discovery process
observed or classified something.

It may not automatically establish that the underlying canonical source has
been directly verified during this Act.

If the underlying source remains unavailable, the preparation record shall be
retained as preparation evidence rather than promoted to direct verification.
