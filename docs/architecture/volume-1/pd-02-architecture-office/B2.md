5. SD-01 — Architecture Model & Structure
5.1 Purpose
SD-01 bertanggung jawab terhadap architectural representation dan system structure yang berada dalam Architecture domain PD-02.
5.2 Primary Responsibility
SD-01 mencakup:
* Architecture Model;
* System Architecture;
* structural representation;
* architectural relationships;
* architecture model integrity.
5.3 Ownership
SD-01 menjadi organizational owner untuk capability yang berkaitan dengan:
Architecture Model & System Structure
Ownership ini merupakan decomposition dari PD-02 ownership terhadap Architecture Model dan System Architecture.
5.4 Primary Outputs
* Architecture Model;
* structural architecture representation;
* model updates;
* structural architecture assessment.
5.5 Primary Consumers
* PD-02 Architecture Leadership;
* architecture decision functions;
* Reference Architecture functions;
* affected Platform Divisions;
* Executive Office ketika architectural structure menjadi strategic context.
5.6 Boundary
SD-01 tidak memiliki ownership terhadap:
* runtime implementation;
* infrastructure implementation;
* AI engineering implementation;
* operational system execution.

32. Criteria for Creating Additional Sub Division
Sub Division baru hanya boleh dipertimbangkan apabila:
1. responsibility tidak dapat ditangani secara coherent oleh existing unit;
2. terdapat distinct capability boundary;
3. terdapat distinct ownership;
4. terdapat distinct output;
5. terdapat distinct consumer;
6. terdapat material boundary;
7. tambahan unit mengurangi overlap, bukan menambahnya.
Tidak boleh membuat Sub Division hanya karena:
* jumlah pekerjaan bertambah;
* kebutuhan staffing;
* preferensi personal;
* organizational fashion;
* keinginan meniru PD-01.
 
⸻
 
33. Criteria for Merging Sub Divisions
Sub Division dapat dipertimbangkan untuk digabung apabila:
* responsibility overlap tinggi;
* boundary tidak material;
* capability terlalu kecil untuk berdiri sendiri;
* consumer dan output sangat dekat;
* separation tidak meningkatkan control atau clarity.
Merge harus mempertahankan ownership traceability.

40. B2 Success Criteria
B2 dianggap berhasil apabila:
1. seluruh primary responsibility PD-02 memiliki organizational home;
2. setiap Sub Division memiliki responsibility yang coherent;
3. tidak terdapat dual primary ownership;
4. setiap Sub Division memiliki boundary yang eksplisit;
5. outputs setiap Sub Division dapat diidentifikasi;
6. consumers setiap Sub Division dapat diidentifikasi;
7. interfaces setiap Sub Division dapat diidentifikasi;
8. Sub Division tidak mengambil domain ownership Platform lain;
9. B2 konsisten dengan A5 authority;
10. B2 konsisten dengan A6 boundary;
11. B2 dapat diturunkan ke capability architecture;
12. B2 dapat diturunkan ke Team architecture;
13. B2 tidak mengunci staffing;
14. B2 tidak mengunci role hierarchy;
15. B2 dapat berkembang tanpa mengubah constitutional foundation.
