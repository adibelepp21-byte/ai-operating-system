## 2. The systemic root cause, established before the register

File 3 `PART VII` requires `SYMPTOM → DIRECT CAUSE → STRUCTURAL CAUSE →
SYSTEMIC CAUSE`. Running that analysis across all twenty-seven gaps produces one
convergent answer, and it determines the outcome of this Act.

```text
SYMPTOM            no P13 gap can be closed
DIRECT CAUSE       File 3 §21.1 requires REQUIRED STATE ACHIEVED for closure
STRUCTURAL CAUSE   required state is undefined for every P13 gap, because no
                   P13 requirement is canonical
SYSTEMIC CAUSE     P13 itself is not defined  →  P13-GAP-0001
```

**Twenty-four of twenty-seven gaps are unclosable for this one reason**, not for
twenty-four separate reasons. Three are inherited P12/platform gaps that are
already owned elsewhere and are not P13's to close.

This is why the register below assigns real resolution *strategies* but almost
no resolution *executions*: the strategies are determinable, and executing them
requires a definition only the Founder can supply. File 3 `§NC-15` — *"candidate
component langsung dipaksakan menjadi architecture"* — forbids manufacturing
that definition to unblock the register.

## 6. Why architecture was not synthesized

`ACT-P13-001 §18` places architecture synthesis after discovery and
reconciliation. Discovery and reconciliation are complete **to the limit of
available sources**, and synthesis still cannot proceed.

`§18` requires architecture to emerge from `CANONICAL SOURCES + CURRENT SYSTEM
REALITY + P13 QUESTIONS + AGENT COMPLETENESS + SYSTEMIC GAP MAP + CROSS-SYSTEM
RECONCILIATION + DEPENDENCY GRAPH + AUTHORITY MODEL + VERIFICATION
REQUIREMENTS`. Of those nine inputs:

```text
AVAILABLE   current system reality · Agent completeness · systemic gap map
            (this record) · partial cross-system reconciliation
ABSENT      canonical sources (0001, 0006) · P13 questions unresolved ·
            dependency graph (blocked on 0001) · authority model (0004) ·
            verification requirements (0027)
```

**Synthesizing from four of nine inputs would be inventing architecture and
searching for justification afterward — precisely the inversion `§18` forbids.**
