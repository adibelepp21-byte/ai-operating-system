## 1. Problem

The Runtime conformance suite forbade `Runtime → Agent`. Four canonical sources
list it as **allowed**. `DEC-P6-038` authorized reconciliation — but §5 forbade
assuming the assertion erroneous merely because it is narrower.

## 2. Canonical evidence — four independent sources, unanimous

| Source | Statement |
|---|---|
| **Freeze §6** | `Runtime hosts Agent Instance` — allowed **Runtime→Instance**; forbidden direction: **—** |
| **Freeze §5** layer 2 | Purpose *"**bind Definition→Instance**; drive execution"* · Inputs *"Agent Definitions"* · Outputs *"Agent Instances"* · **Dependencies: Agent**, Workflow, Tool |
| **Blueprint §6** Runtime Package | Responsibilities *"**create Instances**"* · **Allowed dependencies [A]: *agent*, workflow, and the Tool boundary** |
| **runtime_spec §7** | *"**Depends on Agent Definitions**, Workflows, and the Tool boundary."* |

[E] **Every one of those sources also states a Forbidden list**, and all four
enumerate the same four items: knowledge ownership · independent Trace
authorship (OQ-2) · Instance↔Instance outside Workflow (INV-13) · non-Tool
external dependency (INV-12). **None names agent.**

[E] Blueprint §2 fixes the mapping: *"the dependency directions of the
architecture (Freeze §6) become **import directions** in the tree"* and *"a
forbidden dependency is a forbidden import."*

## 3. Conformance evidence

```
FORBIDDEN_BOUNDARIES  included "agent"
PERMITTED_BOUNDARIES  frozenset({"infrastructure", "knowledge"})  asserted by EQUALITY
```

[E] The forbidding test cited *"INV-13 and OQ-2"*; the permitting test cited
*"Blueprint §26; INV-12."* Tested individually: **Blueprint §26 enumerates
nothing** · INV-12 governs **external/vendor** dependencies · INV-13 governs
**Instance↔Instance** · OQ-2 governs Runtime as a **traced actor**. **None
forbids `Runtime → Agent`.**

## 4. Provenance investigation (§6) — the decisive step

[E] The `"agent"` entry entered in commit **`9731964`** (2026-08-06),
*"test(runtime): add Baseline 04B Runtime conformance suite"* — described in its
own message as a **verification-only baseline**: *"No Runtime source file is
modified by this change."*

[E] Its message attributes the bar to **INV-3**: *"INV-3 hosting is inverted
through the ExecutionConsumer contract; no Runtime → Agent dependency…"*

[E] **The commit carries no `ACT-CC`, `GDR`, `ADR` or `DEC` reference.** No
governing instrument was identified anywhere in the corpus.

[A] **INV-3 does not contain the prohibition attributed to it.** INV-3 is *"One
definition, one host — Instance identity/accountability requires it"* — a
**cardinality** rule. Freeze §6 renders that very invariant as `Runtime hosts
Agent Instance`, direction **Runtime→Instance**, forbidden **none**. The baseline
recorded a Phase 4.2/4.3 engineering inversion **as though it were an invariant
requirement**, and the invariant it cited requires the opposite direction be
available.

## 6. Minimal correction (§14) — two parts, the second proven necessary

**Part 1.** Removed `"agent"` from `FORBIDDEN_BOUNDARIES`, with the four
citations recorded inline. Suite stayed green — because nothing imports agent.

**Part 2, established empirically, not assumed.** A probe placing Freeze §5 layer
2's *"bind Definition→Instance"* in Runtime then failed **exactly one** remaining
assertion: `PERMITTED_BOUNDARIES` asserted by **equality**. Equality pins a
**lower bound** — *"Runtime must reach exactly infrastructure and knowledge"* —
which **no canonical source states**. Canon states only what Runtime *may* depend
on.

Corrected to an **upper bound**: `PERMITTED_BOUNDARIES = {"infrastructure",
"knowledge", "agent"}`, asserted with `assertLessEqual`. The test was renamed
from `..._are_only_the_permitted_two` accordingly.

[A] Part 2 was **not** scope creep. It is the same ungoverned narrowing in a
second form, and the probe proved Part 1 alone leaves the reconciliation inert.

**Affected assertions — four, all in `TestDependencyDirection`:**
`FORBIDDEN_BOUNDARIES` · `PERMITTED_BOUNDARIES` · the cross-boundary assertion
(equality → upper bound, renamed) · one docstring. **No source file changed.**
