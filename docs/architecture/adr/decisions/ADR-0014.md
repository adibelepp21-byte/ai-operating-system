# ADR-0014

## Metadata

- **Identifier:** ADR-0014
- **Title:** The Agent Factory does not unblock E-01; both are blocked by the
  absence of a location that may see two boundaries at once
- **Status:** **Approved** (delegated architecture decision)
- **Decision Owner:** Co-Founder / Delegated Architecture Authority
- **Proposer:** Claude Code / Co-Founder (Construction Phase)
- **Approval Record:** Executed under Founder authorization **DEC-P6-036**,
  which authorizes the Agent Factory as a *prospective* frontier and requires
  the E-01 relationship be **verified, not assumed** (§10).

Creates no new authority, decides no Founder-reserved question, authorizes no
implementation.

---

## 1. Problem

`DEC-P6-036` recognized E-01 as downstream of the Agent Factory and authorized
the Factory as a prospective construction frontier. §10 required the
implementation relationship be verified during this Act rather than assumed.

**It was verified. The premise does not hold.**

## 2. Evidence — the Factory does not unblock E-01

[E] A minimal Factory (`composition.py`, two module-level construction
functions) was built as a probe and run against the Agent conformance suite. It
broke exactly **three** assertions:

```
test_the_boundary_consists_of_exactly_its_declared_modules   structural inventory
test_no_composition_root_exists                              reservation marker
test_no_module_level_function_exists_anywhere                reservation marker
```

[E] **E-01's three blocking assertions did not appear.** They live in
`TestAgentEntersOnlyThroughExecution` — one cross-boundary import fixed by
equality, `Execution` unimportable, the identifier `runtime` forbidden — and the
probe produced **zero** failures in that class. The probe was removed; the suite
is green at 616 OK.

[A] **The Factory and E-01 are blocked by disjoint assertion sets.** Building the
Factory would leave E-01 exactly as blocked as it is today.

## 3. Evidence — what a Factory could legitimately do is already possible

[E] `AgentDefinition` and `AgentInstance` are constructible today; the
conformance suite constructs them, and `__post_init__` already validates every
declared field locally, including INV-2 clause 2's *"at least one Capability."*

[A] What would make it a **Factory** — *governed* construction, validating the
declared keys against real Departments and Capabilities — is the part that is
both structurally impossible and expressly unauthorized:

| Requirement | Status |
|---|---|
| Validate `implemented_capabilities` against real Capabilities | `agent` may not import `capability`; **Capability Binding Authority: NONE** (`DEC-P6-032` item 6, `DEC-P6-033`) |
| Validate `owning_department_key` against real Departments | Same |
| Runtime creates the Instance, per `agent_spec §4` | Runtime's `FORBIDDEN_BOUNDARIES` includes `agent` |

[A] So the constructible slice adds a module-level function around a constructor
that already works. **The reservation is holding nothing of present value; the
value it was reserving is barred elsewhere.**

## 4. The unifying finding

[E] No boundary in the Native Core may import two of the relevant boundaries:

```
agent       PERMITTED = {runtime}                    cannot see capability
capability  declares no runtime/agent access         cannot see agent
runtime     PERMITTED = {infrastructure, knowledge}  cannot see agent or capability
the other nine — none declares runtime or agent access
```

[E] The architecture states the consequence itself. `definition.py`, twice:

> *"…they are reconciled by **a caller that can see both sides**, exactly as
> ownership is."*
> *"…by a caller that can see both sides, never by either boundary reaching into
> the other."*

[A] **That caller has never been built, located, or authorized.** Its absence is
a single cause with three visible effects:

| Effect | Needs to see |
|---|---|
| E-01 cannot be realized | agent **+** runtime beyond the consumer contract |
| Factory cannot validate bindings | agent **+** capability |
| `P7-L-1` — INV-2 unverifiable at the Agent boundary | agent **+** capability **+** department |

[A] These were three findings across three Acts. **They are one finding.** The
Native Core is deliberately a set of mutually blind boundaries; everything
cross-boundary is deferred to a caller above them, and that layer does not exist.

[E] Blueprint §4 scopes its limit precisely: *"The **core** region contains
exactly the eleven frozen subsystem boundaries — no more."* `native_core/` holds
`core/` and `shared/`, and `shared/` is *"a pure sink"* — it may be depended on,
so it cannot depend on boundaries and cannot host a caller. **No composition
region above `core/` exists.**

## 5. Decision

```
Agent Factory readiness:  NOT YET READY
E-01:                     DOWNSTREAM — PREREQUISITE REMAINS
                          (and the prerequisite is NOT the Factory)
```

[A] Per `DEC-P6-036` §14, the precise dependency is identified rather than
construction manufactured. It is **not** missing Phase 4–9 capability. It is two
specific items, both outside delegated authority:

1. **Capability Binding Authority** — currently NONE by `DEC-P6-032`/`DEC-P6-033`.
2. **A composition region that may see more than one boundary** — architecturally
   absent; creating one is a structural decision about the shape of
   `native_core/`, not an implementation choice.

## 6. Phase 4–9 mapping — verified, not assumed

[E] `DEC-P6-036` §3 requires the Master Program's Phase 4–9 Factory mapping be
treated as proposed. **Verified independently:** the consolidating artifact's own
`GAP-05` states it is *"a consolidation, **not a canonical governance
decision**."* The mapping is therefore not canonical, was not relied on, and no
Phase was declared complete.

## 7. Alternatives considered

| Alternative | Outcome |
|---|---|
| Construct the Factory now | Rejected — adds a wrapper around a working constructor; its governing value is barred by items 1–2 of §5 |
| Exercise the reservation markers as the authorization implies | Available, and legitimately reachable under `DEC-P6-036` — but pointless while §5's dependencies stand, and it would spend a reservation for no capability |
| Treat another canonical prerequisite as preceding the Factory (`DEC-P6-036` §15 Alternative D) | **Selected as the finding.** The composition region precedes the Factory |

## 8. Consequences

[A] `DEC-P6-036`'s dependency chain needs one correction, verified this Act:

```
stated     Definition → Factory → Instance → Execution Consumer → Execution
verified   Composition region → { Factory , E-01 }   — both, independently
```

[A] The Factory is not E-01's prerequisite. They are siblings, and their shared
prerequisite is the caller layer.

## 9. What this decision does not do

[A] Relaxes no assertion, constructs nothing, declares no Phase complete, creates
no Phase, redefines no roadmap, touches no protected register, and consumes no
Founder-reserved decision. Suites unmodified; 616 OK.
