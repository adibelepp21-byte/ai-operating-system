# ADR-0015

## Metadata

- **Identifier:** ADR-0015
- **Title:** No composition region is needed — Freeze §5/§6 already grant the
  required cross-boundary visibility, and two conformance suites are narrower
  than canon
- **Status:** **Proposed** — the finding is delegated; **acting on it is
  Founder-reserved**
- **Decision Owner:** Founder (the corrective action) / Co-Founder (the finding)
- **Proposer:** Claude Code / Co-Founder (Construction Phase)

---

## 1. Problem

`DEC-P6-037` recognized a missing composition capability as the common frontier
behind E-01, the Agent Factory and INV-2, and authorized investigation of a
region above `native_core/core/`.

**Investigated. No such region is needed. Canon already grants the visibility.**

## 2. §12.1–12.2 — does a composition region exist?

[E] **No.** `native_core/` contains `core/` and `shared/` only. `shared/` is
canonically *"a pure sink: everything may depend on shared; shared depends on
nothing in core"* (Blueprint §16) — it may not depend on boundaries and cannot
host a caller. `tools/` is read-only validation tooling. **No composition region
exists anywhere, and none is canonical, proposed or reserved.**

## 3. The finding — canon already grants what every blocked target needs

[E] **Freeze §6, Frozen Relationship Rules:**

| Relationship | Allowed direction | Forbidden direction |
|---|---|---|
| **Runtime hosts Agent Instance** | **Runtime→Instance** | **—** *(none listed)* |

[E] **Freeze §5, Frozen Layer Model:**

| Layer | Purpose | Inputs | Outputs | **Dependencies** |
|---|---|---|---|---|
| **2 Runtime** | **bind Definition→Instance**; drive execution | **Agent Definitions** | **Agent Instances** | **Agent**, Workflow, Tool |
| **3 Agent** | definition + governed instance | Runtime | actions, Trace | Runtime, **Capability** |

[E] **Blueprint §2** states the mapping is one-to-one: *"the dependency
directions of the architecture (Freeze §6) become **import directions** in the
tree"* and *"**a forbidden dependency is a forbidden import**."*

[A] Canon therefore grants precisely what the three blocked targets need:
**Runtime → Agent** (Factory, E-01) and **Agent → Capability** (INV-2).

## 4. What the conformance suites assert instead

```
runtime  PERMITTED = {"infrastructure", "knowledge"}   FORBIDDEN includes "agent"
agent    PERMITTED = {"runtime"}                        FORBIDDEN includes "capability"
```

[A] **Both are narrower than Freeze §5/§6.** Freeze §5 layer 2's stated purpose
— *"bind Definition→Instance"* — **is the Agent Factory**, and it is assigned to
Runtime, with Agent among its dependencies.

## 5. The cited basis does not support the narrowing

[E] The runtime assertion cites *"Blueprint §26; INV-12"*, and its forbidden-set
test cites *"INV-13 and OQ-2."* Tested individually:

| Cited authority | What it actually says | Forbids `Runtime → Agent`? |
|---|---|---|
| Blueprint §26 | module isolation principle — **enumerates nothing** | **No** |
| INV-12 | Tool is the only entity permitted an **external/vendor** dependency | **No** |
| INV-13 | no direct **Instance↔Instance** collaboration outside Workflow/Knowledge/scoped Memory | **No** |
| OQ-2 | Runtime *"may not be an independent traced actor"* (Freeze §4) | **No** — says nothing about constructing an Instance |

[A] **None of the four forbids `Runtime → Agent`.** The `"agent"` entry in
`FORBIDDEN_BOUNDARIES` is unsupported by the authorities the test itself cites,
and contradicts Freeze §5 and §6.

## 6. Provenance — the narrowing was never governed

[E] The inversion is stated only in module docstrings (`consumer.py`: *"Direction
of dependency is deliberately inverted… no `Runtime → Agent/Workflow/Skill`
dependency can arise"*) and enforced by conformance assertions.

[E] **No ADR and no GDR governs it.** The only ADR touching the execution layer
is `ADR-0013`, written by this office. `GDR-0002` certified Phase 4 as a *"status
transition on existing evidence… not a governance decision"* and does not address
the inversion.

[A] So the tension is not between two governed decisions. It is **a frozen
canonical relationship versus an ungoverned Phase 4.2/4.3 engineering choice**,
and Charter §10's supremacy order resolves which prevails: Canonical Architecture
sits above Acts and implementation artifacts.

[A] **This is reported, not acted on.** Charter §9.2: identify the conflict, do
not silently adapt, do not silently override, escalate where resolution exceeds
delegated authority.

## 7. §13 — the hypothesis, tested per target

[A] `DEC-P6-037` §13 forbids assuming composition solves the three blockers. Each
evaluated independently, against the *corrected* mechanism (canonical visibility
restored, no new region):

| Target | Needs | Result | Basis |
|---|---|---|---|
| **Agent Factory** | Runtime → Agent | **PROVEN** | Freeze §5 layer 2 *is* the Factory: *"bind Definition→Instance"*, in Runtime, with Agent as a dependency |
| **E-01** | a consumer realization | **PARTIALLY ENABLED** | Same root cause and same assertion family, but E-01 additionally needs `test_runtime_never_learns_of_a_consumer` reconsidered; the Agent-side constraints (`runtime` identifier ban, halt count) are untouched by it |
| **INV-2** | Agent → Capability | **PROVEN in principle, UNCHANGED in practice** | Freeze §5 layer 3 grants Agent → Capability; the agent suite excludes it. Restoring Runtime → Agent alone does **not** help INV-2 — a second, separate correction is required |

[A] **The three are not unblocked by one change.** Factory needs the runtime
correction; INV-2 needs the agent correction; E-01 needs the runtime correction
**plus** its own Agent-side constraints revisited. `DEC-P6-037` §13's requirement
to distinguish rather than bundle was the right instruction — bundling would have
produced a false result.

## 8. §27 outcome

```
OUTCOME D — NO COMPOSITION REGION
Evidence proves another canonical mechanism is intended:
Freeze §5 layer 2 (Runtime binds Definition→Instance) and
Freeze §5 layer 3 (Agent depends on Capability).
```

[A] Building a region above `core/` would have added a layer canon never asked
for, to supply visibility canon already grants. **The architecture was never
missing a composition capability. Two suites are narrower than the architecture.**

## 9. Alternatives (§20)

| | Alternative | Assessment |
|---|---|---|
| **A** | No composition region; a future external mechanism is intended | **Rejected** — canon names the mechanism, and it is internal |
| **B** | Composition region above core | **Rejected** — unnecessary; would add an ungoverned layer to duplicate granted visibility |
| **C** | An existing higher region already serves this | **Rejected** — none exists; `shared/` is a sink by Blueprint §16 |
| **D** | Another canonical mechanism provides the visibility | **SELECTED** — Freeze §5/§6 |

## 10. Capability Binding Authority (§6, §17)

[A] The distinction §17 requires: Capability **existence** (modelled),
**reference** (OPTIONAL per `DEC-P6-033`), **binding**, **validation**,
**authority** — are not interchangeable. INV-2 verification needs *validation*,
which needs Agent → Capability **visibility**, which Freeze §5 layer 3 grants.

[A] **No authority elevation is required to see. Whether validating constitutes
binding — and therefore requires authority beyond NONE — is a Founder question**,
and this ADR does not answer it. §7's instruction is honoured: the authority is
not elevated, and no minimum is asserted beyond "visibility is not authority."

## 11. Consequences and required Founder decision

[D] **Two corrections, both Founder-reserved under `DEC-P6-037` §22** (*changing
the fundamental Native Core boundary model*):

1. **Runtime → Agent** — reconcile the runtime suite with Freeze §5/§6, or
   record why the ungoverned inversion supersedes them.
2. **Agent → Capability** — the same question for the agent suite and INV-2.

[A] Each is a reconciliation of implementation with canon, not a relaxation to
accommodate a build. That distinction matters, and it is why this office declined
the same class of change three times in `ACT-CC-P6-039` through `-041`: there,
the change would have served a construction target. **Here, the change serves
Freeze.**
