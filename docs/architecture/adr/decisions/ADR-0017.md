# ADR-0017

## Metadata

- **Identifier:** ADR-0017
- **Title:** The Agent Factory is built and proven, and blocked by a **mirror**
  of the narrowing ADR-0016 corrected — which canon shows is a decision about
  mutual dependency, not a conformance detail
- **Status:** **Proposed** — finding delegated; **the correction is reserved**
- **Decision Owner:** Founder · **Proposer:** Claude Code / Co-Founder
- **Approval Record:** `ACT-CC-P6-044`, self-created under Charter §12, executing
  **DEC-P6-036 §18** whose readiness condition `ACT-CC-P6-043` satisfied.

## 1. What was built

[E] `runtime/binding.py` — `InstanceBinding`, realizing the responsibility canon
assigns to Runtime alone: *"bind Definition→Instance"* (Freeze §5 layer 2),
*"create Instances"* (Blueprint §6). Constructor-injected against **one** host, so
INV-3's *one host* holds by construction. Fails closed on a non-Runtime host, a
host not RUNNING, and a non-Definition. **Binds, never defines** — canon gives
Runtime Definitions as *input*. Retains nothing: hosting is structural, never a
registry.

[E] With it present: **Runtime conformance 94 OK**, plus **14 behavioural
evidence tests** across one-definition-one-host · fail-closed · actor production
· non-retention · no Trace authorship · and the *deliberate absence* of
Capability validation.

[A] **This is the Agent Factory.** `agent_spec §12/§13` place it in Phase 4;
`P7-L-1` recorded it reserved. It works, where canon puts it.

## 2. What blocks it — exactly one assertion

```
FAIL  TestDependencyDirection.test_no_boundary_outside_agent_depends_on_agent
      "No reverse edge, therefore no cycle: Runtime and every other boundary
       remain unaware of Agent."
```

[E] It scans all of `core/` outside the Agent boundary for **any** import naming
`agent` and asserts the offender list is empty. **Any** Runtime-resident Factory
trips it — the block is structural, not incidental to this design.

[A] It is the **mirror** of the assertion `ADR-0016` corrected. The same four
canonical sources contradict it: Freeze §5 layer 2 (*Dependencies: Agent*),
Freeze §6 (*allowed Runtime→Instance, forbidden —*), Blueprint §6 (*allowed
dependencies: agent*), `runtime_spec §7` (*depends on Agent Definitions*). Its
stated rationale is **cycle avoidance** — an engineering concern — and it cites no
canonical authority.

## 3. The finding the Founder needs before deciding

[A] Removing the ban is **not** merely undoing a second ungoverned narrowing.
**Canon itself specifies a mutual dependency:**

```
Freeze §5 layer 2  Runtime   Dependencies: Agent, Workflow, Tool
Freeze §5 layer 3  Agent     Dependencies: Runtime, Capability
```

[A] Layers 2 and 3 depend on **each other** in the frozen layer model. The cycle
these assertions prevent is one **canon creates**. So the two suites did not
merely narrow canon — between them they imposed an **acyclicity rule the frozen
architecture does not state**, each removing one direction of a mutual edge.

[A] That reframes the decision. It is not *"correct a second oversight."* It is:

> **Does AIOS accept the mutual Runtime ↔ Agent dependency that Freeze §5
> specifies, or does acyclicity govern and Freeze §5 layer 2 need amendment?**

[A] Both readings are coherent. The first restores canon as written and the
Factory ships. The second says the suites encoded a real principle canon omitted,
and then **Freeze §5 layer 2's *"bind Definition→Instance"* has no legal home
anywhere** — which is the condition that has blocked this program for six Acts.

[E] Empirically, the cycle is benign at runtime: with `binding.py` present, the
full import graph resolved and 630 tests ran without an `ImportError`.

## 4. Why this office stopped

[E] `DEC-P6-036 §8.7`: Claude SHALL NOT *"relax frozen Agent-boundary assertions
merely to enable Factory."* Relaxing this one is precisely what would enable the
Factory.

[E] `DEC-P6-038 §9`: SHALL NOT *"modify the Agent boundary."*

[A] The canonical argument here is the same one that carried `ADR-0016`. **The
authority is not.** `ADR-0016` corrected the *Runtime* suite under a Decision
that named Runtime → Agent as its scope; this assertion sits in the Agent suite,
and both governing Decisions reserve it expressly. Argument strength is not
authority — that distinction has held through this whole arc and holds here.

## 5. Disposition

[A] `binding.py` and its 14 evidence tests were **removed**; the suite is green at
**616 OK (1 expected failure)**. Nothing red was left behind and no assertion was
touched. The build is preserved in this ADR, not in the tree.

```
Agent Factory:  BUILT AND PROVEN — BLOCKED BY ONE RESERVED ASSERTION
E-01:           UNCHANGED
INV-2:          UNCHANGED
```

## 6. The exact decision required

[D] **Correct `test_no_boundary_outside_agent_depends_on_agent` to permit the
`Runtime → Agent` edge that Freeze §5/§6, Blueprint §6 and `runtime_spec §7`
grant — and in doing so accept the mutual Runtime ↔ Agent dependency Freeze §5
specifies.**

[A] One assertion, in `native_core/core/agent/tests/test_agent_conformance.py`.
No source file, no Agent contract, no dependency permission of the Agent boundary
itself, and nothing touching Agent → Capability, Capability Binding Authority, or
INV-2.

[A] If instead acyclicity is to govern, that is a **Freeze-level** decision about
layer 2's stated purpose, and it should be recorded as one.
