## 1. What was built

`native_core/core/runtime/discovery.py` — resolution of an **Agent Definition
name** to the declared Runtime host that may host it. Deterministic, fail-closed,
immutable, injected.

```
definition name (str) ─→ governed declarations (data) ─→ HostDeclaration
```

`HostDeclaration(runtime_key, definition_names)` · `DefinitionCatalog` with
`resolve(definition_name, selector=None)`, `declarations`, `from_records(...)` ·
three fail-closed halts extending `RuntimeSubsystemError`.

[E] `native_core/core/runtime/tests/test_definition_discovery_evidence.py` —
**28 tests**, Scopes A–F.

## 2. The decisions, and what forced them

**[A] Decision 1 — a separate collaborator, not methods on `AIOSRuntime`.**
[E] `test_runtime_holds_only_transient_hosting_state` pins
`AIOSRuntime.__dict__` by equality to six attributes;
`test_public_surface_is_exactly_the_contract_plus_identity` pins its public
surface by equality; `Runtime.__abstractmethods__` is pinned at exactly six.
[A] The boundary states plainly that hosting is **structural, not a mutable
collection** (`test_no_hosting_registry_exists`). A collaborator holding no live
actors respects that; a method hanging state off the Runtime would not.

**[A] Decision 2 — not exported, governed by recorded finding F-4.**
[E] `test_recorded_finding_f4_consumer_contract_is_off_the_public_surface`
records that `ExecutionConsumer` — the closest analogue, the Agent-facing
contract — is deliberately off `__all__`, and states: *"It is **not** a repair
and **not** a judgement that the export is required — **the resolution is the
Architect's.**"* [A] Exporting `DefinitionCatalog` would both modify a pinned
inventory and pre-empt a question F-4 explicitly reserves. It is therefore
reachable exactly as `ExecutionConsumer` is:
`native_core.core.runtime.discovery.DefinitionCatalog`. [D] Whether either
belongs on the public surface remains **Founder/Architect reserved**.

**[A] Decision 3 — declarations arrive already decoded; Runtime does no byte
decoding.** [E] This was **corrected by measurement, not foreseen.** The first
implementation carried `from_storage(...)` and imported `json`. The suite
failed:

```
AssertionError: 'json' not found in frozenset({'__future__', 'dataclasses',
'types', 'abc', 'typing', 'enum'}) : discovery.py imports json
```

[A] I did not modify the assertion. The Runtime boundary's stdlib allowlist
admits **no serialization module at all** — that is the architecture speaking:
a boundary that decodes bytes has taken on a facility's work. Infrastructure
owns I/O and encoding (Blueprint §14); Runtime owns interpretation and
resolution. `from_storage` and `json` were removed; `from_records` (pure,
mapping-in) remains. The corrected design is **better**, not merely compliant.

**[A] Decision 4 — resolution yields a declaration, never an Instance.**
[E] `agent_spec §13`: *"The **Agent Factory (Phase 4)** will define governed
construction of Definitions/Instances …; **reserved to the Architect**."*
[A] `resolve()` returns a `HostDeclaration`. No Definition type, no Instance, no
capability binding, no authority. `TestStopsShortOfTheFactory` pins this.

**[A] Decision 5 — naming is constrained by the boundary's own vocabulary.**
[E] `test_no_agent_workflow_or_skill_entity_is_defined_here` forbids any class
name *containing* `Agent`/`Workflow`/`Skill`/`Capability`/`Department`/`Tool`;
`test_no_hosting_registry_exists` forbids the identifiers `registry`, `hosted`,
`agents`, `instances`, `register`, `attach`, `detach`; `trace` is banned as a
substring. [A] Hence `DefinitionCatalog`/`HostDeclaration`/`definition_names`
rather than the obvious `AgentDefinitionRegistry`. The names were chosen to
satisfy the architecture's stated intent, **not** to slip past exact-match
assertions: `hosted_definitions` would have passed the exact-match check and was
still rejected.

| Source | Bearing |

| Roadmap §8 | `Runtime → Agent Definition (dynamically)` — the edge is discovery, not import |

[A] *Dynamic* qualifies **when** a Definition becomes known — at run time, from
data — not **how** a module is loaded. `test_discovery_is_dynamic_in_time_not_
in_python` pins that distinction behaviourally.

## 6. Findings — §17.7

1. **[E] Misleading assertion message (Runtime suite).** The failure reads
   *"discovery.py imports json, **which is not standard library**"*. `json` **is**
   standard library; the frozenset is a per-boundary **allowlist**. The
   constraint is correct and was obeyed; only the message misstates why.
   **Reported, not corrected** — it is a conformance suite, and repairing it is
   not an implementation concern.
2. **[A] Gap: no canonical home for catalog decoding.** Infrastructure exposes
   `StorageFacility.read() -> Iterator[bytes]` but no decode facility, and
   Runtime may not decode. Byte→mapping conversion therefore currently belongs
   to a composition root that does not yet exist for this data. `from_records`
   is deliberately the seam.
3. **[E] Stale legacy path constant.** `docs/architecture/history/legacy-
   execution/governance_reader.py` computes `REPO_ROOT = Path(__file__).
   parent.parent`, which archival broke (found in `ADR-0019` §2). Historical
   evidence; **not modified** — `ACT-CC-P6-047` §14 forbids destroying it.
4. **[D] F-4 export drift remains open** — now with a second occupant.
