# ADR-0023

## Metadata

- **Identifier:** ADR-0023
- **Title:** `ACT-CC-P6-050` halts at its own preconditions — **two independent
  gates** are closed, and clearing either alone unblocks nothing
- **Status:** **COMPLETE — BLOCKED WITH PROOF** (`ACT-CC-P6-050` §20)
- **Decision Owner:** Founder · **Executor:** Co-Founder
- **Approval Record:** `ACT-CC-P6-050` §5 requires execution to stop unless all
  upstream authority is present. It is not. Nothing was implemented.

---

## 1. Why this record exists and what it does not repeat

`ADR-0022` established that the canonical catalog records its hosted
relationship *"by reference only"*. **This ADR does not restate that finding.**
It records three things `ADR-0022` could not: that the block has since been
**re-verified as stable**, that it now consists of **two independent gates**,
and that a **governance defect** currently prevents a formally authorized Act
from starting at all.

## 2. Gate 1 — Founder authority absent — [E]

[E] `ACT-CC-P6-050` §5.1 requires `DEC-P6-041` to exist, be uniquely numbered,
explicitly selected, signed and dated. A repository-wide search returns **no
`DEC-P6-041`**.

[E] The instrument actually issued was numbered **`DEC-P6-040`** — an
identifier already consumed by *Runtime–Agent Discovery Mechanism
Reconciliation*, which is load-bearing in the persisted record: `ADR-0019`
names it as its **Approval Record** (*"Executed under DEC-P6-040 §8/§9/§14"*)
and `ADR-0020` cites it as barring the static `Runtime → Agent` import. [E] That
document's own §17 lists *"DEC-P6-040 — dynamic discovery interpretation"* among
its predecessors, so it is cited as its own antecedent.

[E] Its §21 Founder Decision Record is **unfilled** — no option selected, no
signature, no date — and its status line reads *"PROPOSED FOR FOUNDER
DECISION"*. [E] §7 and §20 carry **"RECOMMENDED: OPTION A"**.

[A] A recommendation is not a decision (`ACT-CC-P6-050` §3.2, §22).
`RECOMMENDED → DECIDED` and `PROPOSED → AUTHORIZED` are promotions this program
forbids, and §22 names this exact failure mode. **§19 stop conditions 1 and 2.**

## 3. Gate 2 — Architect representation absent — [E]

[E] Re-verified independently this Act: no machine-readable hosting field exists
in `runtime-framework.md` or `execution-artifact-repository.md`.

[E] The catalog is **unchanged since `a8c1fbb` (2026-07-31)** — the commit that
first created it. No Architect field has been added. The `## Hosted
Relationship` section still reads, verbatim:

```
- **Hosts Agent Instance:** may host an Agent Instance of the
  [Governance Artifact Integrity Agent](../../platform/agent-definitions/…md)
  (Domain Model §4, Runtime-hosts-Agent-Instance).
```

[A] Prose with a markdown link. None of `ACT-CC-P6-050` §5.2's ten required
items — field name, value grammar, multiplicity, unknown-Definition handling,
duplicate handling, ordering, authority classification, validation
responsibility, canonical location, relationship to the existing declaration —
is resolved anywhere in canon. **§19 stop conditions 3 and 4.**

## 4. The gates are independent — [A]

[A] This is the determination worth recording, and it is not in `ADR-0022`:

```
Gate 1  Founder authority          →  DEC-P6-041, uniquely numbered and signed
Gate 2  Architect representation   →  specification resolving §5.2's ten items
```

[A] **Neither gate implies the other.** A signed `DEC-P6-041` selecting Option A
would authorize a *semantic direction* and still leave Gate 2 closed — the Act's
own §12 and its EXECUTION INSTRUCTION both require a STOP in exactly that
state. Conversely an Architect specification without a Founder selection would
lack the authority to be consumed.

[A] So `ACT-CC-P6-050` cannot reach §6 Required Discovery, let alone
implementation, until **both** close. Any report that clearing one "unblocks
the frontier" would be false.

## 5. What was NOT done — [E]

[E] No schema, field name, value grammar, wildcard, duplicate rule, ordering
rule, unknown-Definition rule, authority classification, or validation
ownership was invented (§14). [E] No implementation file, test, conformance
assertion, or canonical document was created or modified. [E] The
link-extraction heuristic measured under `ACT-CC-P6-049` remains `[I]`
inference and was **not** promoted, reused, or persisted.

[A] The plausible schema is precisely the thing to refuse. `ACT-CC-P6-049`
demonstrated a working end-to-end resolution using an invented extraction rule;
that demonstration is evidence the *seam* works, and **no evidence at all**
about what the canonical representation should be.
