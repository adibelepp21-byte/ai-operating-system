# 2. Interface Architecture Principle

> **Organizational interfaces connect responsibilities and interactions between organizational units without creating reporting relationships, transferring ownership, or creating authority.**

Interface architecture harus memungkinkan:

- clear interaction;
- clear responsibility boundary;
- controlled information exchange;
- explicit handoff;
- cross-domain alignment;
- dependency visibility;
- escalation routing.
