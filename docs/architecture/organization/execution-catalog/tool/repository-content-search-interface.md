## Purpose / Description

An integration point (Domain Model §2) providing text-search access
over a specified scope of AIOS repository content, returning matching
locations for a given query. Stated only in the abstract; names no
specific technology, vendor, or model (Domain Model §8, Constitution
§6.2 invariant 1).

## Interface

Accepts a search scope and a query expression. Returns a list of
matching locations within that scope. Records this Tool's current
interface boundary (Tool Framework §9); does not interpret Domain
Model §6 beyond that.
