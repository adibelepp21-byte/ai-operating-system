## Purpose / Description

An integration point (Domain Model §2) that compares two passages of
governance-document text and returns a measure of how similar their
wording is, for the purpose of identifying likely-duplicated content.
Stated only in the abstract.

## Interface

Accepts two text passages. Returns a similarity measure between them.
Records this Tool's current interface boundary (Tool Framework §9).
