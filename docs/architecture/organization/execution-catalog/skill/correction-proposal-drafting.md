## Purpose / Description

A discrete, bounded unit of executable ability (Domain Model §2) that,
given an identified inconsistency in a governance document, drafts
proposed replacement wording for the affected passage, without
applying it. Stated only in the abstract. This Skill claims no
approval or governance authority; any resulting change still requires
approval at the tier appropriate to what is being changed, per
Constitution §3.

## Interface

Accepts a description of an identified inconsistency and its location.
Produces proposed replacement wording for that location. Records this
Skill's current interface boundary (Skill Framework §9).
