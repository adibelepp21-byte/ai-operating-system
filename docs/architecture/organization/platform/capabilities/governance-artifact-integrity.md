# Governance Artifact Integrity

This Capability was established by
[ADR-0003](../../../adr/decisions/ADR-0003.md), owned by the
[Platform](../README.md) Department. This document records that
decision; it does not itself grant or define any authority.

## Name

Governance Artifact Integrity

## Owner

Platform Department

## Definition

Maintain the internal consistency and accuracy of AIOS's governance
artifacts — the Engineering Constitution, the Canonical Domain Model,
and their subordinate procedural documents — so that no artifact
diverges from what it describes or duplicates another artifact's
authoritative content.

## Scope

This Capability covers the Engineering Constitution, the Canonical
Domain Model, the ADR Framework, the Organization Framework, and any
future governance or procedural documents within AIOS's own semantic
and governance substrate. It does not cover product- or business-domain
content, which belongs to future Departments' own Capabilities once
established.

## Status

No Agent Definition currently implements this Capability. Per ADR-0003,
this is an expected, temporary condition following the Capability's
creation, not an oversight — an Agent Definition is expected to be
created promptly as ordinary Department-discretion work, outside the
scope of any ADR.
