## 0. What this step is

`R3` is the Roadmap's own entry gate. It requires establishing seven state
inputs and returning **exactly one** of four verdicts:

```text
P10 READY
P10 READY WITH BOUNDED OPEN ITEMS
P10 BLOCKED
P10 REQUIRES FOUNDER DECISION
```

with the instruction: **"Do not manufacture readiness."**

**This artifact returns that verdict.** Reaching a `BLOCKED` result is executing
`R3`, not declining it — `R3` supplies the outcome slot precisely because the
answer may be negative.
